# 03. 文件目录操作

> **模块说明**：本模块覆盖服务器端文件系统相关操作，包括盘符查询、目录遍历、目录创建、文件大小查询、文件读取、Blob 最大长度查询及质量码格式化等 Raw API。

---

## 1. RawRtdbGetLogicalDriversWarp — 获得逻辑盘符

**函数签名**：`func RawRtdbGetLogicalDriversWarp(handle ConnectHandle) ([]string, RtdbError)`

| 用例编号 | 用例标题 | 前置条件 | 输入数据 | 操作步骤 | 预期结果 | 优先级 |
|---------|---------|---------|---------|---------|---------|--------|
| TC-DRIVERS-01 | Windows 平台获取盘符 | 连接 Windows 服务器 | handle 有效 | 调用 `RawRtdbGetLogicalDriversWarp` | 返回 `RteOk`，切片包含 C、D、E 等盘符 | P1 |
| TC-DRIVERS-02 | Linux 平台获取盘符 | 连接 Linux 服务器 | handle 有效 | 调用 `RawRtdbGetLogicalDriversWarp` | 返回 `RteOk`，切片包含 `/` | P1 |
| TC-DRIVERS-03 | 无效句柄 | handle = -1 | handle = -1 | 调用 `RawRtdbGetLogicalDriversWarp` | 返回 `RteInvalidHandle` | P2 |
| TC-DRIVERS-04 | 未登录获取盘符 | 仅连接未登录 | handle 有效 | 调用 `RawRtdbGetLogicalDriversWarp` | 返回 `RteHaveNotLogin` | P2 |

## 2. RawRtdbOpenPathWarp — 打开目录以便遍历

**函数签名**：`func RawRtdbOpenPathWarp(handle ConnectHandle, dir string) RtdbError`

| 用例编号 | 用例标题 | 前置条件 | 输入数据 | 操作步骤 | 预期结果 | 优先级 |
|---------|---------|---------|---------|---------|---------|--------|
| TC-OPENPATH-01 | 打开存在的目录 | 已登录，目录存在 | dir="/data" 或 "C:\\rtdb" | 调用 `RawRtdbOpenPathWarp` | 返回 `RteOk`，后续可遍历 | P1 |
| TC-OPENPATH-02 | 打开不存在的目录 | 已登录 | dir="/nonexistent" | 调用 `RawRtdbOpenPathWarp` | 返回路径不存在错误 | P2 |
| TC-OPENPATH-03 | 打开文件而非目录 | 已登录，路径为文件 | dir="/data/file.txt" | 调用 `RawRtdbOpenPathWarp` | 返回不是目录错误 | P3 |
| TC-OPENPATH-04 | 空路径 | 已登录 | dir="" | 调用 `RawRtdbOpenPathWarp` | 返回参数错误 | P3 |
| TC-OPENPATH-05 | 无效句柄 | handle = -1 | dir="/data" | 调用 `RawRtdbOpenPathWarp` | 返回 `RteInvalidHandle` | P2 |
| TC-OPENPATH-06 | 无权限目录 | 已登录，目录权限不足 | dir="/root" | 调用 `RawRtdbOpenPathWarp` | 返回 `RteAccessIsDenied` | P3 |

## 3. RawRtdbReadPath64Warp — 读取目录中的文件或子目录（64位）

**函数签名**：`func RawRtdbReadPath64Warp(handle ConnectHandle) (DirItem, RtdbError)`

| 用例编号 | 用例标题 | 前置条件 | 输入数据 | 操作步骤 | 预期结果 | 优先级 |
|---------|---------|---------|---------|---------|---------|--------|
| TC-READPATH-01 | 遍历目录下第一个条目 | 已打开有效目录 | handle 有效 | 调用 `RawRtdbReadPath64Warp` | 返回 `RteOk`，DirItem 包含 Path、IsDir、Size、时间戳 | P1 |
| TC-READPATH-02 | 遍历至目录结束 | 已打开目录，所有条目已读完 | handle 有效 | 继续调用 `RawRtdbReadPath64Warp` | 返回 `RteBatchEnd` | P1 |
| TC-READPATH-03 | 未调用 OpenPath 直接读取 | 未打开目录 | handle 有效 | 调用 `RawRtdbReadPath64Warp` | 返回错误（如 `RteNotOpened`） | P2 |
| TC-READPATH-04 | 无效句柄 | handle = -1 | handle = -1 | 调用 `RawRtdbReadPath64Warp` | 返回 `RteInvalidHandle` | P2 |
| TC-READPATH-05 | 验证返回字段类型 | 已打开含文件和子目录的目录 | handle 有效 | 循环调用至结束 | 文件条目 IsDir=OFF，目录条目 IsDir=ON；Size 对文件非负 | P2 |
| TC-READPATH-06 | 空目录遍历 | 已打开空目录 | handle 有效 | 调用 `RawRtdbReadPath64Warp` | 首次调用即返回 `RteBatchEnd` | P3 |

# 11. 历史数据写入与修改

> **模块说明**：本模块覆盖历史数据的单值写入、批量写入（含模拟量、坐标型、Blob/String、Datetime、自定义类型），以及历史值的修改、删除和缓存刷新等相关 Raw API。

---

## 一、单值写入

### 1. RawRtdbhPutSingleValue64Warp — 写入单个标签点历史数据

**函数签名**：`func RawRtdbhPutSingleValue64Warp(handle ConnectHandle, id PointID, datetime TimestampType, subtime SubtimeType, value float64, state int64, quality Quality) RtdbError`

| 用例编号 | 用例标题 | 前置条件 | 输入数据 | 操作步骤 | 预期结果 | 优先级 |
|---------|---------|---------|---------|---------|---------|--------|
| TC-PUTS-01 | 正常写入浮点型数据 | 已登录，ID 为 RTDB_REAL64 | value=123.45, state=0 | 调用 | 返回 `RteOk`，后续查询该时间点 value=123.45 | P1 |
| TC-PUTS-02 | 正常写入整型数据 | 已登录，ID 为 RTDB_INT32 | value=0, state=100 | 调用 | 返回 `RteOk`，后续查询 state=100，value 被忽略 | P1 |
| TC-PUTS-03 | 写入未来时间戳 | 已登录 | datetime=当前时间+1h | 调用 | 返回 `RteOk` 或未来时间不允许错误 | P2 |
| TC-PUTS-04 | 重复时间戳覆盖 | 已登录，该时间点已有数据 | 同时间，不同 value | 调用 | 返回 `RteOk`，数据被覆盖或返回已存在错误 | P2 |
| TC-PUTS-05 | 无效标签点 ID | 已登录 | id=-1 | 调用 | 返回 `RteInvalidParameter` 或点不存在错误 | P2 |
| TC-PUTS-06 | 无效句柄 | handle=-1 | — | 调用 | 返回 `RteInvalidHandle` | P2 |
